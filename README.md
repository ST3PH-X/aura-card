## 🧠 The Math: Julia Set Shader Pipeline

Under the hood, AuraCard bypasses the standard CPU execution loops and compiles raw GLSL (OpenGL Shading Language) fragment shaders directly on your GPU lanes. The infinite visual complexity you see on the screen is generated by iteratively computing a single non-linear complex matrix formula for every single pixel coordinate:

$$Z_{n+1} = Z_n^2 + C$$

### 🛠️ Hardware Execution Steps:

1. **Text DNA Hashing:** Every single character of your text input is captured and passed through a deterministic reduction algorithm. This string hash compiles a steady numeric pair used as the complex number constant $C$ (the invariant mathematical seed of the system).
2. **Complex Space Mapping:** The WebGL context normalizes your screen resolution into a complex number plane where $Z_0$ represents the $X$ and $Y$ screen coordinates of a pixel.
3. **The GPU Core Iteration Loop:** For each pixel, the shader executes the quadratic equation up to **64 times**:
   - If the absolute magnitude $|Z|$ shoots past the escape boundary ($> 4.0$), it breaks out. The speed of its mathematical escape determines the brilliant neon color gradient and wave frequency.
   - If the sequence remains bound forever, it sinks into the infinite darkness of the fractal’s inner core.

## 🛠️ Tech Stack & Architecture

- **Core Graphics:** Raw HTML5 WebGL context without Three.js or heavy rendering frameworks.
- **Typography Matrix:** Inline responsive font-family injection combined with a hardware-synced reflow system (`scaleText`) to avoid canvas cross-origin taint.
- **Export Engines:** 
  - **Static PNG:** Direct hardware videobuffer screen capture via instant data streaming.
  - **Animated SVG:** Zero-asset vector files embedding a procedural CSS hue-shifting phase loop (`infiniteFlow`). The animation runs natively inside the downloaded asset without loading external libraries.
